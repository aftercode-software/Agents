# Imagen

## Objetivo visual

Acompañar la publicación con capturas reales de Legali sin convertirla en una pieza publicitaria.

## Tipo de imagen

Tres imágenes originales aportadas por el usuario: una vista general del producto, una referencia del problema y una pantalla de trabajo de Legali.

## Prompt o instrucciones

No se generó ni se editó una imagen nueva. Se conservaron las imágenes aportadas por el usuario.

## Formato sugerido

Publicación de LinkedIn con texto y las tres imágenes originales adjuntas.

## Notas de privacidad

Las capturas se usaron tal como fueron aportadas. Conviene revisar que los datos visibles de las interfaces sean de prueba antes de publicar públicamente.
